# Blinkit-Dashboard

A dynamic analytics dashboard I built for Blinkit, India's leading 10-min grocery delivery platform.This repository is particularly based on the past data and current analysis.

## Overview 
- This dashboard will help client to analyze the business trends in different tiers (Tier 1,2,3). 

- Also analyzes which categroy of products were buyed in different outlets.

- Multi line DAX (uploaded the image in images folder)used for creating KPI card for average and total sales, number of items and average rating.

## Key Visualization 

- Donut charts: For the fat classification (Low, Regular fat) and outlet tier revenue.

- Line chart: Shows the revenue trends over the years from 2011 - 2022.

- Table: Helps to get the revenue and quantity analysis for different market types.
